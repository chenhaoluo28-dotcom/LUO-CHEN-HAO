# 虾仁风 / 沙雕动画风格圣经

## 1. 这个风格是什么

“虾仁风”是中文互联网沙雕动画的一种常见方向：

- 角色常用熊猫头、表情包脸或极简贴图头像
- 身体是简化人形，衣服、朝代和身份靠一两件标志物识别
- 背景低细节，优先保证动作、表情和包袱可读
- 历史穿越、现代梗、职场、校园、修仙、宫廷、系统流都可混搭
- 节奏快，前 3 秒就要出现冲突、反差或离谱信息
- 情绪表演夸张，动作幅度大，常用速度线、震屏、定格、闪白、冲击波
- 台词短、口语化、带网络梗，但不要堆到观众读不完
- 典型结构：正经铺垫 → 荒诞转折 → 递进升级 → 终极打脸/反转 → 新钩子

这个 Skill 只借用**类型方向**。不要复制任何真实创作者的角色、剧情、台词、形象、封面或素材。

## 2. 风格矩阵

开工前先锁定以下参数：

| 参数 | 选项 |
|---|---|
| 时代 | 古代朝堂、武侠江湖、修仙宗门、校园、职场、赛博、末世、混合穿越 |
| 主角身份 | 师爷、暴君、店小二、赘婿、外卖员、打工人、学生、捕快、宗门废柴 |
| 能力系统 | 无系统纯沙雕、评分系统、任务系统、弹幕系统、签到系统、历史模拟器 |
| 反差来源 | 现代知识 vs 古代规则、弱身份 vs 强后台、正经外表 vs 沙雕行为 |
| 喜剧密度 | 低（剧情为主）、中（每 10 秒一梗）、高（每 3–5 秒一梗） |
| 画幅 | 9:16 竖屏（抖音/快手/视频号）、16:9 横屏（B站/YouTube 长视频） |
| 单集时长 | 30 秒开胃、60–90 秒标准、120–180 秒长集 |
| 结尾钩子 | 新人物、新系统提示、身份揭晓、灾难预告、打脸预告、悬念问题 |

## 3. 故事引擎

### 3.1 一句话故事

```text
一个【身份/缺陷】的【主角】，在【时代/世界】里获得【异常能力/系统】，
本想【低目标】，却被【对手/规则】逼着【升级行动】，最后【反转结果】。
```

### 3.2 单集结构

默认 60–90 秒：

| 时间 | 功能 | 要求 |
|---|---|---|
| 0–3 秒 | 黄金钩子 | 冲突、羞辱、离谱字幕、系统提示或视觉反差 |
| 3–10 秒 | 规则建立 | 让观众秒懂主角处境和本集目标 |
| 10–25 秒 | 第一个包袱 | 荒诞转折，观众第一次笑 |
| 25–45 秒 | 递进升级 | 反派加压、主角反击、系统加码 |
| 45–65 秒 | 终极反转 | 打脸、身份揭晓、意外胜利 |
| 65–75 秒 | 结尾钩子 | 新威胁、新系统、新人物或下集预告 |

### 3.3 包袱类型

- 预期违背：观众以为要正经，结果离谱
- 身份反差：废物其实是隐藏大佬
- 现代梗错位：外卖、KPI、弹幕、短视频、热搜进入古代
- 反复升级：同一个梗连续三次，一次比一次大
- 打脸延迟：先让反派得意 2–3 秒，再反转
- 系统吐槽：系统提示与主角内心 OS 形成相声式对话
- 视觉反差：可爱熊猫头做狠事，或威严角色做沙雕动作

## 4. 角色资产模板

每个角色分配稳定 ID，建议 1–3 个核心角色 + 2–4 个功能角色。

```text
## CHAR-001 · 角色名

- 定位：主角/反派/捧哏/系统/工具人
- 性格：3 个关键词
- 缺陷：1 个明确缺陷
- 目标：本集想要什么
- 视觉锚点：
  - 头像/脸型：
  - 身体比例：
  - 固定服装：
  - 配色：
  - 标志物：
  - 禁止漂移：
- 表情库：开心、愤怒、悲伤、惊讶、平静、紧张、得意、尴尬、害怕、思考
- 沙雕夸张表情：瞳孔地震、嘴角抽搐、石化、灵魂出窍、下巴掉地
- 姿态库：站立、奔跑、跪地、抱头、指点、拍桌、后退、摔倒
- 声线：年龄感、音色、语速、口音、标志性语气

可复制角色板提示词：
[风格] + [角色完整外观] + [三视图] + [同一身份锚点] + [背景] + [无文字/无LOGO]
```

### 4.1 角色一致性锁

每个角色至少写一条“连续性锁”，例如：

```text
CHAR-001=熊猫头表情包脸，圆耳，黑眼圈，红色方巾，墨绿短打，腰系麻绳，体型五头身。
```

这条锁要能原样贴进图片和视频提示词。不要用同义词替换。

## 5. 场景资产模板

```text
## SCENE-001 · 场景名

- 时代/地点：
- 空间锚点：门、桌、窗、柱子、牌匾、台阶等固定物
- 光线：方向、色温、时段
- 材质：木、石、布、金属、纸、霓虹
- 色彩：主色、辅色、点缀色
- 机位变体：全景、中景、过肩、俯拍、仰拍
- 禁止漂移：不能改变布局、招牌文字、门窗位置
```

场景板提示词模板：

```text
[风格]，[场景类型]，[固定空间锚点]，[光线方向与色温]，[材质与色彩]，
无人，平视机位，固定建筑结构，[画幅]，无文字，无LOGO，无水印
```

```text
- 外观：
```


## 7. 视觉语言

### 7.1 角色

- 头像：熊猫头、表情包脸、夸张五官
- 身体：2–5 头身，轮廓清楚，动作幅度大
- 服装：1–2 个高识别元素就够，避免细节过多导致跨镜漂移
- 表情：比写实动画夸张 1.5–2 倍

### 7.2 背景

- 低细节、平涂色块、简化材质
- 保留固定空间锚点
- 不在背景堆无关人物和小物件
- 时代、天气、光线变化要单独登记

### 7.3 动效

- 速度线、集中线、冲击波、震屏、闪白、闪黑、定格
- 人物呼吸起伏、头发飘动、衣角摆动
- 道具掉落、茶杯震动、纸张翻飞
- 系统面板和 UI 在剪辑阶段叠加，默认不生成进视频

### 7.4 镜头语法

| 目的 | 镜头 |
|---|---|
| 建立场景 | 大全景/全景，1–2 秒 |
| 交代关系 | 双人中景、过肩镜 |
| 台词 | 中近景、胸上景 |
| 反应 | 特写、大特写，0.5–1.5 秒 |
| 道具信息 | 插入特写 |
| 打脸 | 反打 + 推镜 + 定格 |
| 追逐/打斗 | 快切、跟拍、甩镜 |
| 反转 | 先给反派得意特写，再切主角冷静特写 |

## 8. 对白与旁白

- 单句尽量 ≤15 字
- 用口语，不用书面语
- 重要信息用“角色说 + 动作”同步
- 内心 OS 无口型，标注“闭口，画外音”
- 系统语音单独标注音色，例如“机械女声，短促，带电流底噪”
- 台词按 4–5 字/秒估算时长

## 9. 声音设计

### 9.1 声音层

```text
对白 > 动作音效 > 环境底声 > BGM
```

### 9.2 常用音效

- 打脸：啪、脆响、回音
- 震惊：咚、锣、玻璃碎、乌鸦叫
- 系统：叮、提示音、电流声
- 搞笑：弹簧、滑音、鼓点、木头敲击
- 反转：唱片刮擦、静音、低频轰鸣

### 9.3 BGM

- 开场：紧张/滑稽/史诗感反差
- 中段：轻快、悬疑、鼓点推进
- 打脸：鼓点 + 停顿 + 爆发
- 结尾钩子：悬疑低音或突然静音

## 10. 提示词骨架

### 10.1 角色板

```text
沙雕动画角色设定板，[角色外观连续性锁]，正面、三分之二侧面、背面三视图，
同一脸型、同一身高比例、同一服装，纯色背景，[画幅]，无文字，无LOGO，无水印。
```

### 10.2 表情板

```text
同一角色的九宫格表情板，[角色连续性锁]，开心、愤怒、悲伤、惊讶、得意、
尴尬、害怕、思考、沙雕夸张，九格身份完全一致，[画幅]，无文字，无LOGO。
```

### 10.3 场景板

```text
[场景连续性锁]，[固定空间锚点]，[光线]，[时段]，无人，平视，[画幅]，
无文字，无LOGO，无水印。
```

### 10.4 视频镜头

```text
从[起点状态]开始。[触发]后，[角色ID+名称]先[预备动作]，
再[主体动作与接触点]，最后[缓冲动作与终点状态]。
摄影机[固定/一次有动机的运动]。环境[变化]。声音：[台词/OS/音效]。
[明确终点]。全程不生成字幕、花字、LOGO、水印。
```

## 11. 交付检查

- [ ] 主角/反派/捧哏是否有稳定视觉锚点
- [ ] 角色表情是否能一眼读懂
- [ ] 场景是否有固定空间锚点
- [ ] 道具跨镜状态是否一致
- [ ] 前 3 秒是否有钩子
- [ ] 每 10 秒是否至少有一次转折
- [ ] 结尾是否有下集钩子
- [ ] 台词是否能按 4–5 字/秒说完
- [ ] 视频提示词是否只含画面、动作、声音和限制条件
- [ ] 是否没有复制真实创作者的角色、剧情、台词或形象
