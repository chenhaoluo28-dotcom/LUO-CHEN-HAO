# AI 漫剧全流程提示词库

这个文件把 AI 漫剧从创意到成片的提示词拆成 15 个阶段。每个阶段都可以单独调用，也可以按顺序跑完整流程。

所有提示词默认中文。使用英文模型时，把提示词结构保留，内容改成英文即可。

## 0. 项目启动

### 用途

锁定题材、平台、画幅、时长、模型、风格和限制条件。

### 提示词

```text
你是虾仁风沙雕漫剧的制片人。请根据我给的信息，补全项目启动卡。

已知信息：
- 创意：
- 目标平台：
- 画幅：
- 单集时长：
- 目标模型：
- 风格参考：
- 不能出现的内容：

请输出：
1. 一句话故事
2. 题材与赛道
3. 目标观众
4. 本集承诺
5. 前3秒钩子方向
6. 结尾钩子方向
7. 需要固定的角色/场景/道具ID
8. 仍需确认的最少问题（最多1个）

如果信息不足，直接用合理默认值补齐，不要连续追问。
```

## 1. 标题与钩子

### 用途

生成标题、封面文案、前 3 秒钩子和下集预告。

### 提示词

```text
你是短视频漫剧标题与钩子专家。根据下面的故事，生成：
1. 10个标题，每个不超过18字，必须有冲突或反差
2. 5个前3秒钩子文案
3. 5个封面大字文案
4. 3个结尾钩子
5. 3个下集预告
6. 对应的话题标签

要求：
- 不用标题党到与内容无关
- 前3秒必须有：羞辱、危机、离谱信息、系统提示或身份反差
- 结尾钩子必须引出下一集的明确问题

故事：
[粘贴一句话故事或本集梗概]
```

## 2. 故事引擎与分集

### 用途

把创意扩展成可连续更新的故事引擎。

### 提示词

```text
你是沙雕漫剧故事策划。根据下面的创意，设计一个可连续更新的故事引擎。

请输出：
1. 主角：身份、缺陷、欲望、秘密
2. 反派/对手：目标、压力来源、打脸点
3. 捧哏/工具人：功能、笑点来源
4. 能力/系统：规则、代价、升级方式
5. 世界规则：主角不能轻易打破什么
6. 单集公式：每集如何重复但不重复
7. 前5集钩子链
8. 20集升级线

要求：
- 每集必须有一个独立小目标和一个结尾钩子
- 主角不能靠无代价开挂解决一切
- 反派每次升级都要让打脸更爽

创意：
[粘贴创意]
```

## 3. 逐拍剧本

### 用途

把故事变成可拍的 beat sheet 和剧本。

### 提示词

```text
你是虾仁风沙雕漫剧编剧。把下面的故事写成第1集逐拍剧本。

输出格式：
【第1集：标题】
总时长：
前3秒钩子：
结尾钩子：

| 拍号 | 时间 | 场景 | 角色 | 可见动作 | 台词/OS | 情绪变化 | 包袱/反转 | 镜头目的 |

规则：
- 每句台词不超过15字
- 台词按4-5字/秒估算时长
- 心理活动必须变成动作、表情或声音
- 每10秒至少一次信息/情绪转折
- 结尾必须留钩子
```

## 4. 角色、场景、道具资产

### 4.1 角色资产

```text
你是漫剧角色设计师。为下面每个角色生成可跨镜复用的资产卡。

每个角色输出：
- CHAR ID
- 定位
- 性格关键词
- 缺陷
- 视觉锚点：头像/脸型、身体比例、服装、配色、标志物
- 禁止漂移项
- 10种基础表情
- 5种沙雕夸张表情
- 5种常用姿态
- 声线卡
- 角色板图片提示词

要求：
- 视觉锚点必须能被逐字复用到每一张图片和视频提示词
- 标志物要一眼可识别
- 不要复制任何真实创作者的角色
```

### 4.2 场景资产

```text
你是漫剧场景设计师。为下面每个场景生成场景资产卡。

每个场景输出：
- SCENE ID
- 时代/地点
- 固定空间锚点：门、窗、桌、柱、牌匾、台阶
- 光线方向与色温
- 主色/辅色/点缀色
- 材质
- 机位变体
- 禁止漂移项
- 场景板图片提示词

要求：
- 空间锚点必须固定，后续镜头不能改变门窗位置
- 背景保持低细节，避免抢角色和动作
```

### 4.3 道具资产

```text
你是漫剧道具师。为下面每个关键道具生成资产卡。

每个道具输出：
- PROP ID
- 用途
- 外观
- 状态变体
- 归属角色
- 出现镜头
- 图片提示词
```

## 5. 分镜

### 用途

把剧本变成可生成的镜头表。

### 提示词

```text
你是虾仁风沙雕漫剧分镜师。把下面的剧本拆成镜头，严格返回CSV表格。

列：
SHOT ID,时长,画面目的,焦段,景别,摄影机位置,摄影机运动,起始状态,预备动作,主体动作,缓冲动作,台词/OS,音效,emotionStart,emotionEnd,终点状态,下一镜衔接

硬性规则：
1. 一个镜头只写一个主要动作
2. 动作镜头必须有“预备-主体-缓冲”，三段时长相加等于镜头时长
3. 对话按4-5字/秒估算时长，最小0.8秒
4. 无对话纯动作镜头1-3秒
5. 场景变化拆新镜头
6. 每句关键台词给一个镜头或一个反应镜
7. 情绪必须有emotionStart→emotionEnd
8. 多人同镜必须写清每个人的画面位置和动作
9. 道具交接、手部接触、左右关系必须写清
10. 视频不生成字幕和花字

剧本：
[粘贴逐拍剧本]
```

## 6. 图片提示词

### 6.1 角色板

```text
[风格]，[CHAR ID与连续性锁]，正面/三分之二侧面/背面三视图，
同一脸型、同一身高比例、同一服装、同一标志物，
纯色背景，全身，[画幅]，无文字，无LOGO，无水印
```

### 6.2 表情板

```text
同一角色的九宫格表情板，[角色连续性锁]，
开心、愤怒、悲伤、惊讶、平静、紧张、得意、尴尬、害怕、思考、沙雕夸张，
九格身份完全一致，[画幅]，无文字，无LOGO
```

### 6.3 姿态板

```text
同一角色的姿态板，[角色连续性锁]，
站立、奔跑、跪地、抱头、指点、拍桌、后退、摔倒、得意叉腰、震惊后仰，
同一身份、同一服装，[画幅]，无文字，无LOGO
```

### 6.4 场景板

```text
[SCENE ID与连续性锁]，[固定空间锚点]，[光线方向与色温]，[时段]，
无人，平视机位，固定建筑结构，[画幅]，无文字，无LOGO
```

### 6.5 道具板

```text
[PROP ID与外观]，同一比例尺下的[状态A/状态B/状态C]，
同一光线，纯色背景，无手，[画幅]，无文字，无LOGO
```

### 6.6 关键帧

```text
[镜头目的]，[角色ID]在[画面位置]，[姿态]，[表情]，
[场景ID]的[固定锚点]在[位置]，[景别]，[角度]，[光线]，
[画幅]，无文字，无LOGO，无水印
```

### 6.7 封面

```text
短视频漫剧封面，[主角ID]在画面[位置]，
[夸张表情]，[核心冲突道具]，[场景ID]，
画面留出标题区，[画幅]，标题文字由后期添加，不生成文字
```

## 7. 通用视频提示词

### 用途

先写和模型无关的动作说明，再按模型改写。

### 提示词

```text
你是漫剧视频提示词导演。根据下面的镜头卡，写一条通用视频提示词。

必须包含：
1. 从[起点状态]开始
2. 触发事件
3. 角色先[预备动作]
4. 再[主体动作+方向+接触点]
5. 最后[缓冲动作+终点状态]
6. 一条并行变化
7. 摄影机：固定或一次有动机的运动，写清起止构图
8. 环境与光线变化
9. 对白/OS/VO/音效，按发生顺序
10. 终点状态
11. 禁止字幕、花字、LOGO、水印

只写要拍出来的内容，不写文件名、版本号、规则编号或制作备注。

镜头卡：
[粘贴镜头卡]
```

## 8. Seedance 2.0 提示词

```text
[风格总纲]，[角色]@图片1，[场景]@图片2

0-3秒：[画面、动作、镜头]
4-8秒：[接续动作、反应、镜头]

台词（角色A，情绪）："台词内容"
音效：[环境音 + 动作音效]
时长：精准X秒
禁止：文字、字幕、LOGO、水印
```

规则：

- 单段通常不超过 15 秒
- 台词用引号包裹
- 音效单独成行
- 分段之间写清衔接点
- 下一段可用 `将@视频1延长X秒`

## 9. Seedance 2.5 提示词

```

### 11.1 声音时间线

```

### 11.2 音效提示词

```text

- 时长：X秒
- 质感：[清脆/沉闷/金属/木头/电子/卡通]
- 空间：[近景/远景/室内/室外]
- 音高：[低/中/高]
- 尾巴：[立即收/带回音/渐弱]
- 用途：[打脸/震惊/系统/搞笑/反转]
```

## 12. 剪辑与字幕

### 12.1 剪辑单

```text
| SHOT ID | 入点 | 出点 | 时长 | 画面内容 | 声音 | 字幕 | 转场 | 备注 |
```

规则：

- 前 3 秒必须完成钩子
- 台词与口型对齐
- 打脸前留 2–3 秒得意时间
- 反转处可用定格、震屏、静音
- 字幕在剪辑阶段添加，不从视频生成

### 12.2 字幕表

```text
| 时间 | 角色 | 字幕文本 | 样式 | 动效 |
```

### 12.3 字幕样式提示词

```text
漫剧字幕样式：白色粗体，黑色描边，底部居中，
关键词用黄色高亮，重要台词可震屏放大，逐字浮现，
字号适配竖屏9:16，不遮挡角色嘴部和关键道具。
```

## 14. 审查与返修

### 14.1 审查提示词

```text
请按以下维度审查这一集：
- 前3秒钩子
- 每10秒转折
- 包袱密度
- 角色一致性
- 场景连续性
- 道具状态
- 动作可生成性
- 台词时长
- 音效层级
- 平台包装
- IP与版权风险

输出：
| 维度 | 评分0-5 | 问题 | 证据 | 修复建议 |
```

### 14.2 返修提示词

```text
根据审查结果重写[SHOT ID]。
只改一个问题：[问题]
保留：[必须保留的动作/台词/情绪/连续性]
修改后输出新的完整提示词。
```

## 15. 批量生成

```text
请为第1集生成批量提示词包。

先输出：
- 镜头总数
- 图片任务数
- 视频任务数
- 配音任务数
- 音效任务数
- 预计总时长

然后按以下格式输出：

| 任务ID | 类型 | 关联SHOT | 参考资产 | 参数 | 可复制提示词 | 检查项 |

规则：
- 同一参考资产编号保持稳定
- 每个角色每次出现都带同一绑定
- 视频任务禁止字幕、花字、LOGO、水印
- 先给预览，不自动执行付费生成
```

## 16. 提示词卫生

交付文本只保留生成需要的画面、动作、声音和限制条件。不要把以下内容放进可复制提示词：

- 文件名、版本号、目录路径
- 内部规则编号、hash、状态词
- 走位草图编号
- 失败记录、重投备注
- 与本镜无关的负面清单
- 没有对应可见动作的抽象情绪

如果一个提示词删掉某个形容词后画面没有变化，删掉它。
