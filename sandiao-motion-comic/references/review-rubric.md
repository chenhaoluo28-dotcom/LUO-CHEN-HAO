# 虾仁风沙雕漫剧审查表

交付前逐项检查。每项 0–5 分，总分 60。低于 42 分不建议直接生产。

## 1. 评分表

| 维度 | 0–5 分 | 检查问题 |
|---|---|---|
| 前 3 秒钩子 | | 观众为什么要停下来？有没有冲突、危机、离谱信息或身份反差？ |
| 单集目标 | | 这一集主角想要什么？阻碍是什么？观众能不能一句话说清？ |
| 节奏 | | 每 10 秒是否至少有一次信息、情绪或视觉转折？ |
| 包袱/爽点 | | 中段是否有 3–5 个递进包袱或打脸点？ |
| 结尾钩子 | | 结尾是否留下明确的新问题、新威胁或新身份？ |
| 台词效率 | | 每句是否 ≤15 字？是否按 4–5 字/秒能说完？ |
| 表演可见性 | | 情绪是否全部转成了动作、表情、呼吸、节奏或声音？ |
| 角色一致性 | | 每个角色的视觉锚点是否跨镜一致？有没有替换同义词？ |
| 场景连续性 | | 空间锚点、光线、时间和机位是否连续？ |
| 道具连续性 | | 道具数量、归属、状态、手持关系是否一致？ |
| 动作可生成性 | | 是否一镜一主动作？起止、路径、接触点是否清楚？ |
| 声音设计 | | 对白、OS、VO、动作音效、环境音、静默是否有层级？ |
| 平台包装 | | 标题、封面、标签、前 3 秒文案、下集预告是否齐？ |
| IP/版权 | | 是否复制了真实创作者的角色、剧情、台词或形象？ |

## 2. 硬性失败项

出现以下任意一项，直接返修，不进入生产：

- 前 3 秒没有任何钩子
- 主角在全集中没有明确目标
- 结尾没有钩子
- 角色视觉锚点跨镜不一致
- 多人同镜只写“他/她”，无法分辨谁在做什么
- 一镜内塞入多个互不依赖的大动作
- 动作没有起点、触发、路径、接触点或终点
- 台词说不完
- 视频提示词要求模型生成字幕、花字、LOGO 或水印
- 直接复制受保护 IP 的角色、剧情、台词或标志性形象
- 视频提示词里混入文件名、版本号、规则编号、失败记录

## 3. 故事审查

### 3.1 开场

- 第 1 秒是否有视觉冲击或信息冲击？
- 第 3 秒前是否让观众知道主角处境？
- 是否用动作而不是旁白交代背景？

### 3.2 中段

- 反派是否先得意 2–3 秒再被打脸？
- 包袱是否递进？第三次是否比第一次更大？
- 主角是否有一次失败、误判或代价？
- 是否每 10 秒给一次新信息？

### 3.3 结尾

- 是否在最强反转后立刻切走？
- 是否留下下一集必须回答的问题？
- 是否有下集预告或系列推进方向？

## 4. 视觉审查

- 角色头像、服装、配色、标志物是否每镜一致？
- 表情是否夸张到一眼读懂？
- 场景是否保留固定空间锚点？
- 光线方向是否跨镜一致？
- 道具是否没有凭空出现、消失、复制或换手？
- 背景是否足够简单，不抢主体？

## 5. 动作审查

每条动作镜头检查：

- [ ] 起点姿态清楚
- [ ] 触发事件清楚
- [ ] 预备动作
- [ ] 主体动作
- [ ] 接触点或地标
- [ ] 缓冲动作
- [ ] 终点姿态
- [ ] 摄影机固定或一次有动机的运动
- [ ] 只有一条并行变化

## 6. 声音审查

- [ ] 每个角色有稳定声线
- [ ] 台词发声者、对象、情绪和语气清楚
- [ ] OS 闭口，VO 不对口型
- [ ] 动作音效与动作同步
- [ ] 环境底声贯穿场景
- [ ] 点缀音效低于对白
- [ ] 反转处是否用停顿、静音或音乐落点
- [ ] BGM 是否留给后期

## 7. 提示词审查

逐条可复制提示词检查：

- [ ] 只包含画面、动作、声音和限制条件
- [ ] 没有文件名、版本号、目录、规则编号
- [ ] 角色、场景、道具每次出现都带同一绑定
- [ ] 左右关系明确
- [ ] 一镜一主动作
- [ ] 终点状态明确
- [ ] 不生成字幕、花字、LOGO、水印
- [ ] 精确文字镜头只允许指定文字和指定位置

## 8. 平台审查

### 抖音/快手/视频号

- 9:16
- 前 3 秒钩子更强
- 字幕大、节奏快
- 结尾 1 秒内留钩子

### B站/YouTube

- 16:9 或 9:16
- 可以稍长，但每 15–20 秒仍需转折
- 封面和标题可以更有信息量
- 简介里可以放系列说明

## 9. 返修协议

```text
问题：
证据：
影响：
只改一个变量：
保持不变的项：
修改后结果：
是否通过：
```

返修优先级：

1. 版权/合规
2. 故事目标和结尾钩子
3. 角色一致性和连续性
4. 动作可生成性
5. 台词时长
6. 节奏和包袱
7. 包装和标签
