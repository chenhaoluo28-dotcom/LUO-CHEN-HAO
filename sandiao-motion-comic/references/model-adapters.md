# 目标模型适配

目标模型的名称、能力和参数会变化。下面只写**可迁移的写法差异**，不承诺任何模型当前的具体规格。提交前以目标工具的当前文档为准。

## 通用规则

无论是图片还是视频模型，先写不绑定供应商的通用描述，再按目标模型改写：

1. 起点状态
2. 触发
3. 有序动作与物理接触点
4. 表演变化
5. 摄影机
6. 环境与光线
7. 台词/OS/VO/音效
8. 明确终点
9. 文字与缺陷约束

一个镜头只保留一个主要动作。并发堆太多元素会降低稳定性，应拆镜。

## Seedance 2.0

- 使用中文自然语言
- 用 `@图片1`、`@图片2` 绑定角色、场景和道具参考
- 长镜头用 `0-3秒：... 4-8秒：...` 的时间戳分镜
- 单段通常不超过 15 秒
- 单段提示词保持精简，避免超出模型的文本上限
- 台词用引号包裹，标注角色与情绪
- 音效单独成行
- 结尾固定写：`禁止：文字、字幕、LOGO、水印`
- 适合：短动作、对话、单场景反转

模板：

```text
[风格总纲]，[角色]@图片1，[场景]@图片2

0-3秒：[画面、动作、镜头]
4-8秒：[接续动作、反应、镜头]

台词（角色A，情绪）："台词内容"
音效：[环境音 + 动作音效]
时长：精准X秒
禁止：文字、字幕、LOGO、水印
```

## Seedance 2.5

- 与 2.0 共用导演逻辑
- 单个分镜组可更长，但仍以一个完整事件或动作段落为边界
- 不为了凑时长加空镜
- 如果一镜内包含多个互不依赖的动作，优先拆成多个镜头组
- 继承角色、场景、道具绑定
- 台词和音效分轨写清

## Kling

- 强调主体、动作、环境、镜头运动、光影
- 支持图生视频时，参考图主要控制身份和外观，不自动带入未要求的动作
- 动作描述要短而具体
- 手部接触、道具交接、左右关系必须写清
- 适合：人物动作、表情、单场景连续镜头

模板：

```text
[主体]，[起始姿态]，[触发]后[主要动作]，[接触点]，[终点姿态]。
摄影机[固定/推/拉/摇/跟拍]。[环境与光线]。
不出现字幕、文字、LOGO、水印。
```

## Runway

- 提示词可中英混写，短句优先
- 常用结构：subject + action + camera + scene + lighting + style
- 图生视频时，参考图决定起点和外观
- 避免一镜多动作
- 运镜关键词要写动机和终点

模板：

```text
[Subject] [action]; camera [movement]; [scene]; [lighting]; [style];
no subtitles, no text, no logo, no watermark.
```

## Hailuo / MiniMax

- 中文自然语言优先
- 适合人物表情、对话、轻动作
- 描述动作路径、接触点和终点
- 台词、OS、VO 分开发声者与语气
- 用“禁止字幕/文字/LOGO/水印”收尾

## Vidu

- 多主体一致性是重点
- 用参考图绑定每个角色和场景
- 多人同镜时每个角色都重复绑定和空间位置
- 不适合一镜塞入太多并发动作

## Wan

- 中文自然语言
- 动作要简单、物理因果清楚
- 图生视频时写清起点帧和运动方向
- 避免复杂手部操作和多人交接

## Pika

- 提示词短、画面感强
- 运动强度不要同时拉满
- 强调镜头运动、主体动作和风格
- 适合：单个喜剧动作、表情变化、短反转

## Midjourney

- 适合角色板、表情板、场景板、封面
- 角色连续性靠固定“身份标签组”重复
- 常用参数：`--ar 9:16`、`--ar 16:9`、`--style raw`、`--niji`（按需）
- 多角色同框要用空间位置词分隔
- 负面词单独写

模板：

```text
[quality/style], [character identity tags], [expression/action], [scene],
[shot size], [lighting], [style], [aspect ratio]
```

## Stable Diffusion / ComfyUI

- 标签式提示词 + 独立负面提示词
- 角色一致性建议使用角色 LoRA、IP-Adapter、参考图或固定 seed
- 角色身份标签组放在前面
- 负面词集中写：变形、多手多脚、模糊、水印、文字、多个视角、设计不一致
- 适合：批量角色板、表情板、姿态板

模板：

```text
Positive: [quality], [character tags], [expression], [action], [scene], [lighting], [style]
Negative: (worst quality:1.4), (low quality:1.4), deformed, bad anatomy,
extra limbs, missing fingers, blurry, watermark, text, signature,
multiple views, inconsistent design
```

## Flux

- 自然语言优先，不需要堆质量标签
- 侧重场景叙述、材质和光线
- 多角色同框时写空间关系和前后景
- 适合：高质量场景板、关键帧、封面

## 图片提示词配方

### 角色板

```text
[风格]，[角色ID与连续性锁]，正面/三分之二侧面/背面三视图，
同一脸型、同一身高比例、同一服装，纯色背景，[画幅]，
无文字，无LOGO，无水印
```

### 表情板

```text
同一角色的九宫格表情板，[角色连续性锁]，
开心、愤怒、悲伤、惊讶、得意、尴尬、害怕、思考、沙雕夸张，
九格身份完全一致，[画幅]，无文字，无LOGO
```

### 场景板

```text
[场景ID与连续性锁]，[固定空间锚点]，[光线方向与色温]，[时段]，
无人，平视机位，固定建筑结构，[画幅]，无文字，无LOGO
```

### 关键帧

```text
[镜头目的]，[角色ID]在[画面位置]，[姿态与表情]，
[场景ID]的[固定锚点]在[位置]，[景别与角度]，
[光线]，[画幅]，无文字，无LOGO
```

## 视频提示词配方

```text
从[起点状态]开始。
[触发]后，[角色ID+名称]先[预备动作]，
再[主体动作+方向+接触点]，
最后[缓冲动作+终点状态]。
与此同时[一条并行变化]。
摄影机[固定/一次有动机的运动]，[起始构图]→[终点构图]。
环境[光线/风/雨/尘埃变化]。
声音：[对白/OS/VO/SFX，按发生顺序]。
最终[明确终点]。全程不出现字幕、花字、LOGO、水印。
```

## 负面提示词

```text
字幕，对白文字，花字，标题，水印，LOGO，签名，多余手指，缺手，多手，
多脚，肢体变形，脸崩，五官漂移，服装变化，角色变色，场景穿帮，
道具消失，道具复制，镜头抖动，闪烁，过度模糊，重复人物
```

## 精确文字镜头

只有上游明确要求某个屏幕、牌匾、榜单或系统面板必须可读时，才使用 `exact-readable`：

- 只允许指定文字和指定显示位置
- 不同时写全局“无文字”
- 提示词中写清唯一可读内容，例如“屏幕顶部一行显示：全站创作者榜 第1位”
- 如果参考图带未批准文字，先裁切、遮罩或替换
- 字幕层仍然禁止

## 适配检查

- [ ] 是否选择了目标模型的具体格式
- [ ] 是否一个镜头只有一个主动作
- [ ] 参考图是否用稳定编号绑定
- [ ] 每个角色每次出现是否都带同一绑定
- [ ] 台词是否挂载到具体动作拍
- [ ] 音效是否单独成行
- [ ] 是否禁止字幕、文字、LOGO、水印
- [ ] 是否写清终点状态
- [ ] 是否避免一镜多动作和多主体身份混淆
